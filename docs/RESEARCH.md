## 5. M1 格式實測(D-0008 第 7 點)

工具:本 repo 的實測頁(`npm run dev`)。**真實螢幕錄影的實測還沒做**;下面只有能在開發環境確認的部分,不能當格式大小的結論引用。

### 已確認

| 項目 | 結果 | 方式 | 日期 |
|---|---|---|---|
| Chromium 能否直接錄 MP4 | 能。`MediaRecorder.isTypeSupported('video/mp4;codecs=avc1')` 為真,錄出 640×360、編碼 `avc` 的 MP4,可以讀回 | Claude 桌面版內建瀏覽器(Chromium 156),來源是 canvas 畫面,不是螢幕分享 | 2026-11-27 |
| 框選裁切 | 1280×720 來源框選 (100, 100, 640, 360),輸出 640×360,框的左上角對到來源的 (100, 100) | 同上,檢查輸出 GIF 最後一格的像素 | 2026-11-27 |
| 五種輸出都產生得出來、讀得回 | MP4 H.264、WebM VP9、WebM AV1 能播放、長度正確;動態 WebP、GIF 用 `ImageDecoder` 讀到全部格數、無限循環 | 同上,來源是 3 秒的合成畫面 | 2026-11-27 |
| 動態 WebP 只送變動範圍時畫面是否正確 | 和同一份取樣的 GIF 逐格比對,平均每通道差 0.2 ~ 0.3(0 ~ 255) | 同上 | 2026-11-27 |
| 實測頁打包大小 | JS 580 KB,gzip 後 154 KB(大部分是 mediabunny,`ALL_FORMATS` 會帶進所有格式的讀取器) | `vite build` | 2026-11-27 |
