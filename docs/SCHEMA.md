# SCHEMA — 步驟清單與播放套件格式

錄製頁、轉檔、播放元件共用這份格式(`CLAUDE.md` §8)。格式改變時,和程式放同一個 PR 更新,三邊一起改,並處理舊版清單。不自動載入(D-0001)。

> **格式版本 1,已定版**(D-0012)。之後改欄位要升 `version`,並寫明舊版怎麼讀。

## 1. 播放套件

套件就是專案檔(D-0009 第 2 點)。同一份內容有兩種樣子:

- **zip:** 用來傳遞、保存,拖回錄製頁繼續編輯。
- **資料夾:** zip 解壓後放上網頁,播放元件讀資料夾裡 `manifest.json` 的網址。播放元件不讀 zip(D-0012 第 4 點)。

```
<教學名稱>.zip
├─ manifest.json
└─ steps/
   ├─ 01-<id>.mp4      H.264(D-0011)
   ├─ 01-<id>.jpg      海報圖(影片載入前顯示)
   └─ …
```

- 檔名的序號只是方便看;順序以 `manifest.json` 的 `steps` 陣列為準,排序時不改檔名。
- `<id>` 是步驟建立時產生的 6 碼小寫英數(`[a-z0-9]{6}`),同一份套件裡不重複。重錄時換新影片檔,但 `id` 不變。

## 2. `manifest.json`

```json
{
  "format": "stepreel",
  "version": 1,
  "title": "新增聯絡人",
  "size": { "width": 1280, "height": 720 },
  "background": "#ffffff",
  "player": { "advanceAfterLoops": 2 },
  "steps": [
    {
      "id": "k3f9a2",
      "video": "steps/01-k3f9a2.mp4",
      "poster": "steps/01-k3f9a2.jpg",
      "duration": 4.8,
      "trim": { "start": 0.6, "end": 4.1 },
      "scale": 2,
      "crop": { "x": 120, "y": 80, "width": 1280, "height": 720 }
    }
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `format`、`version` | 是 | `format` 固定 `"stepreel"`,`version` 是格式版本(目前 `1`)。見 §4 |
| `title` | 是 | 給錄製頁與檔名用;播放元件**不顯示**(D-0008 第 3 點) |
| `size` | 是 | 輸出尺寸,以第一步的框選為準;每步等比縮放後置中(D-0009 第 5 點) |
| `background` | 否 | 置中後四周的底色,預設白色 |
| `player.advanceAfterLoops` | 否 | 播完幾次自動到下一步;省略或 `0` 表示不自動前進(D-0009 第 3 點)。這是套件的預設值,播放元件的屬性可以覆寫(D-0012 第 5 點) |
| `steps[].id` | 是 | 見 §1 |
| `steps[].video` | 是 | MP4 H.264(D-0011)。路徑規則見 §3 |
| `steps[].poster` | 否 | 修剪後第一格的 JPEG;修剪起點改了就重新產生(D-0012 第 6 點)。路徑規則見 §3 |
| `steps[].duration` | 是 | 影片長度(秒,修剪前) |
| `steps[].trim` | 否 | 修剪後的起訖(秒,`0 ≤ start < end ≤ duration`);省略表示整段。修剪不重新編碼(D-0009 第 5 點) |
| `steps[].scale` | 是 | 這一步錄製時的放大倍率,`1` 或 `2`(D-0011)。影片尺寸是框選的 `scale` 倍,播放時一樣等比縮進 `size`;重錄時沿用這個倍率(D-0012 第 2 點) |
| `steps[].crop` | 是 | 這一步在螢幕畫面上的框選範圍(像素,`scale` 套用前)。`video` 是錄影時已經套用框選的畫面,播放與轉檔不再依 `crop` 裁切;`crop` 只用來重錄時沿用 |

步驟沒有文字欄位:不放標題、說明(D-0008 第 3 點)。步驟編號由陣列順序決定,不存。

## 3. 路徑規則

`video`、`poster` 只能是套件裡的相對路徑(相對於 `manifest.json`):

- 不能是網址(含 `http:`、`data:`、`blob:`、`//` 開頭),不能以 `/` 開頭;
- 不能含 `..` 或反斜線。

錄製頁匯入與播放元件讀取時都要檢查,不符合的步驟不載入並提示(D-0012 第 3 點)。

## 4. 版本

- `format` 不是 `"stepreel"`,或沒有 `version`:不是本工具的套件,錄製頁與播放元件都拒絕讀取。
- `version` 比程式認得的新:播放元件照常播(忽略不認得的欄位);錄製頁可以開,但提示存檔時可能遺失新版欄位。
- `version` 比程式認得的舊:讀取時轉成目前版本,存檔時寫目前版本。目前只有版本 1。

## 5. 單一 MP4 與動圖的匯出選項

不寫進 manifest,每次匯出時選:要不要在角落燒步驟編號徽章(D-0009 第 4 點)。

## 6. 實作時要驗證

格式已定版,下面只影響播放元件與轉檔的做法,不影響欄位:

- `trim` 用 `currentTime` 控制 MP4 起訖在 Chrome、Edge、Safari 是否夠準、循環時會不會閃。在播放元件的任務實機驗證;不夠準先在播放元件裡處理,仍不行才寫新決策改成匯出時重新編碼(會推翻 D-0009 第 5 點)。
