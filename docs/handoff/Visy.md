## 接手時容易漏掉的事

- repo 是公開的:錄影樣本、匯出的 zip 不要進 git;另一個專案的名稱與內部內容不要寫進本 repo。
- 播放元件讀資料夾,不讀 zip(R-018);路徑要照 `docs/SCHEMA.md` §3 檢查。
- 改步驟清單格式時,錄製頁的暫存(`docs/SCHEMA.md` §7)也要一起處理。
- `getDisplayMedia` 在內建瀏覽器無法自動測;要用合成 canvas 錄影(`/src/convert.ts` 的 `toPackageVideo`),或請 Visy 在 Chrome 實測。
- 專案的 `ship` 流程:內建 `/ship` 只做程式碼審查,不跑 `rules-security-reviewer`、不覆寫交接檔,送出時要補做。
