## 接手時容易漏掉的事

- repo 是公開的:錄影樣本、匯出的 zip 不要進 git;另一個專案的名稱與內部內容不要寫進本 repo。
- 螢幕分享在畫面不動時不送新格:轉檔時最後一格要延長到實際錄影時間(`CONVENTIONS.md` §5)。
- 錄製頁的狀態鎖是 `busy`(錄影、轉檔、匯入期間);暫存寫入也要避開這段時間的半成品。
- `getDisplayMedia` 在內建瀏覽器無法自動測;要用合成 canvas 錄影,或請 Visy 在 Chrome 實測。
- 專案的 `ship` 流程:內建 `/ship` 只做程式碼審查,不跑 `rules-security-reviewer`、不覆寫交接檔,送出時要補做。
