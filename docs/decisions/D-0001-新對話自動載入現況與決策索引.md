## 決定

1. `CLAUDE.md` §0 以 `@` 匯入 `docs/STATUS.md`、`docs/DECISIONS.md`、`docs/CONVENTIONS.md`,每段新對話啟動時自動載入。
2. 不自動載入:`PROJECT.md`、`docs/SCHEMA.md`(任務牽涉背景、資料表或 API 時才讀)、個別決策檔(索引已載入)、`WORKFLOW.md`、`docs/ONBOARDING.md`、`docs/SHELVED.md`、範本。
3. 個人交接檔由每人在 repo 根目錄自建 `CLAUDE.local.md` 匯入(一行 `@docs/handoff/<自己的名字>.md`);這個檔案不進 git。

## 理由

- Claude Code 開新對話不會自動帶入 `docs/` 的知識,每次都要貼「請先讀這些」。
- 只匯入每個任務都要看的三份(現況與未決事項、決策與否決清單、技術慣例);全部匯入會佔掉每段對話的空間、稀釋重點。
- 交接檔一人一份,寫進共用 `CLAUDE.md` 會讓每個人都載入別人的交接檔。
