## 決定

1. **通用的教學錄製工具,不綁任何專案。** 任何網頁、任何桌面程式都能錄。
2. **錄製端是純網頁。** 用瀏覽器的螢幕分享(`getDisplayMedia`)選分頁、視窗或整個螢幕,在預覽上拖拉框選範圍,錄的時候只留框內的畫面,用 `MediaRecorder` 錄影,不必安裝。支援桌機的 Chrome、Edge。手機畫面先投到電腦再錄(Android 用 scrcpy,iPhone 用鏡像)。
3. **一個功能拆成幾個步驟,一步錄一段。** 每段是無聲、循環播放的短片。影片裡完全不放文字(不燒字幕,播放端也不加步驟說明),只有步驟編號。
4. **三種輸出:**
   - **網頁播放套件**(主要):一份步驟清單(manifest)加每步一段影片,由工具提供的播放元件放進任何網頁;
   - **單一影片檔**:所有步驟接成一支 MP4,可以直接傳 LINE、放進簡報;
   - **動圖檔**:動態 WebP,另附 GIF,給只收圖片的地方用。
5. **轉檔全部在瀏覽器裡做。** 影片用 WebCodecs 加封裝函式庫,GIF 用小型編碼器。不依賴 ffmpeg 或伺服器。實際用哪個函式庫,依 `CONVENTIONS.md`「新增第三方套件」審查後再定。
6. **錄製頁用 GitHub Pages 提供。** repo `mogumyceliummind/stepreel` 是公開的,進 git 的內容一律當成公開內容(`CLAUDE.md` §8)。
7. **檔案大小以實測為準。** 同一段錄影分別輸出 MP4(H.264)、WebM(VP9、AV1)、動態 WebP、GIF,量大小與畫質,結果寫在 `docs/RESEARCH.md`。Chrome 能不能直接錄 MP4 也一併實測。實測前,影片比 GIF 小多少只是經驗值,不能當結論引用。

## 理由

- 被教學的畫面常改版;一步一段的話,改了哪一步只要重錄那一步。
- 錄影比 GIF 小,原因是 GIF 只有 256 色、幾乎沒有跨畫面壓縮,中文字和漸層也會糊;H.264、VP9、AV1 只存變動的部分。影片用 `muted loop playsinline autoplay` 播放,在手機上看起來就跟動圖一樣。
- 純網頁不用安裝:Windows、Mac 都只要打開網頁,也能錄非網頁的程式(選整個螢幕再框選),符合「任何環境」。
- 影片裡不放文字,改說明不必重錄;也不必處理多語系與字型。
- 獨立 repo:工具不屬於任何一個專案,其他專案用的時候不必拿到那些專案的程式與決策。
