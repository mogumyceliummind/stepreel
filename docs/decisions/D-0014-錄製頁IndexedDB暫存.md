## 決定

1. **暫存的內容 = 套件的內容。** 一份版本 1 的步驟清單(`toManifest` 產生,只把 `video`、`poster` 路徑換成 `<id>/video.mp4`、`<id>/poster.jpg`),加上每步的影片與海報 Blob。外面包一層暫存記錄,有自己的格式版本 `draftVersion`(目前 1)與暫存時間。復原時走跟匯入 zip 相同的驗證(`fromManifest`)。格式見 `docs/SCHEMA.md` §7。
2. **只暫存「有步驟、還沒匯出」的內容。** 匯出成功(匯出期間沒有再改)、清空、匯入 zip、刪光所有步驟之後,把暫存清掉;正本是匯出的 zip(D-0009 第 2 點、R-008)。
3. **寫入時機:** 每次變更(錄好、重錄、刪除、排序、插入、修剪、海報重新產生、名稱與設定)後 0.4 秒寫入,一次一個排隊寫。影片只在 Blob 換了才重寫,步驟清單與 Blob 在同一個交易裡寫,不會只寫一半。錄影、轉檔、匯入期間不必暫停:步驟列表都是在完成時同步換上,任何時候拍下的狀態都是完整的。
4. **開頁時:** 有暫存就跳出對話框,選「復原」或「丟棄」。按 Esc 關掉當作「先不決定」:暫存留著,這次不自動暫存(離開時照舊提示),重新整理後可以再選。暫存的 `draftVersion` 比程式新時只能丟棄或留著。復原失敗(含所有步驟都沒通過驗證)時暫存留著、這次不自動暫存,不靜默清掉。「先不決定」或復原失敗之後,只要匯出、清空或匯入,舊暫存就清掉並開始自動暫存(第 2 點);另一個分頁的暫存不動。
5. **同時只有一個分頁暫存。** 用 Web Locks 取得暫存權;第二個分頁不暫存,頁面上提示「另一個分頁正在編輯」。
6. **離開提示:** 有未匯出的步驟、而且最新的變更還沒寫進暫存(或這個分頁沒有在暫存)時才提示。
7. **寫入失敗**(空間不足等)時在頁面上提示請先匯出 zip,不中斷編輯。

## 理由

- **存套件的內容、走同一套驗證:** 暫存能直接轉成套件,不必另外定一份格式;暫存被別的版本或手動改壞時,也只會略過壞掉的步驟,不會讓頁面壞掉。路徑用步驟 id 而不是序號,排序時不必重寫影片。
- **匯出後清掉:** 暫存只是「還沒匯出」的保險;匯出後留著,下次開頁會問一個沒必要的問題,也容易讓人把瀏覽器當成正本(R-008)。
- **用對話框強制選:** 沒選就開始錄,第一次自動暫存會蓋掉舊的暫存;Esc 留一條不決定的路。
- **鎖分頁:** 兩個分頁各自暫存會互相蓋掉,且開頁的復原會拿到另一個分頁的半成品。
- **不另開 `navigator.storage.persist()`:** 暫存只是保險,正本是 zip;被瀏覽器清掉的情況頁面上已經說明。實際使用時常被清掉再改。

## 已知限制與取捨

- 換電腦、換瀏覽器、清除網站資料就沒了(頁面上有說明)。
- 錄影中途重新整理或關掉頁面,正在錄的那一段不會留下。
- 選「先不決定」之後的編輯不會暫存,只靠離開提示。
