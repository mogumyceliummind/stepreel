|---|---|

| 範圍 | `CLAUDE.md` §1 |
| 相關 | D-0001 ~ D-0004 |

## 決定

1. 改了通用的工作流(`CLAUDE.md` 骨架、`WORKFLOW.md`、`.claude/`、`.github/`、文件範本),而且其他專案也用得到時,同一個任務結束前在範本 repo `claude-workflow-template` 另開分支與 PR 回饋。
2. 只回饋通用的部分;專案專屬內容(決策內容、紅線、技術棧細節)不搬,引用的決策編號改成範本自己的編號。
3. 範本不會自動連動已建立的專案;要不要把範本的新版本拉回本專案,由本專案自己決定。

## 理由

- 從範本建立的專案各自演化,改進若只留在單一專案,下一個專案又要重新踩一次。
- 要求「同一個任務結束前」做,是因為事後再回頭補,通常就忘了。
- 範本是 Template repository,建立後與各專案沒有連動,所以回饋要人(或 Claude)主動做。

## 否決的方案

(無)

## 誰決定了哪一部分

- 沿用工作流範本。本專案確認時,在這裡寫上確認者與日期;不需要回饋時可推翻這一號。
