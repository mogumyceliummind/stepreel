# stepreel

在瀏覽器裡錄操作教學:框選螢幕的一塊範圍,一步錄一段無聲短片,輸出成

- **網頁播放套件**:步驟清單加每步一段影片,用播放元件放進任何網頁;
- **單一 MP4**:所有步驟接成一支,可以直接傳訊息、放進簡報;
- **動態 WebP / GIF**:給只收圖片的地方用。

不必安裝,錄製與轉檔都在瀏覽器裡做。支援桌機的 Chrome、Edge。

> 開發中,尚無可用版本。
